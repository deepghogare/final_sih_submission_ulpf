Workflow Stage Descriptions

1. Ingestion Layer

Accepts raw log input via CLI batch processing or REST API stream. Utilizes multi-worker ThreadPool execution for high throughput.

2. Format Detection & Parsing

Identifies log syntaxes (JSON, CSV, Syslog, CEF, LEEF, XML) using content signatures and dynamic plug-and-play parser plugins.

3. Cryptographic SHA-256 Integrity

Calculates a deterministic SHA-256 hash on raw input bytes and assigns a collision-deduplicated unique Event ID.

4. Dynamic Priority Mapping

Detects log vendor signatures and maps vendor fields to the standard schema using a 6-tier fallback configuration engine.

5. Normalization & Asset Enrichment

Standardizes timestamps to ISO 8601 UTC, normalizes actions/severities, and performs offline IP subnet/host database lookup.

6. Pydantic V2 Schema Validation

Enforces strict schema compliance. Corrupt or unparseable records route safely to the Dead-Letter Queue without stopping execution.

7. Persistence, Blockchain & SIEM

Stores events in JSONL/SQLite, seals blocks into an immutable Merkle Blockchain ledger, and forwards alerts to Wazuh SIEM.
